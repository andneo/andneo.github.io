Network-forming liquids are unusual because their thermodynamics depend on connectivity over many length scales, not only on local coordination. I look for compact structural descriptions that reveal which collective network motifs actually matter.

A recurring theme is that phase behaviour becomes easier to interpret when a liquid is treated as a physical network embedded in three-dimensional space. Rings can link, networks can interpenetrate, and those topological changes can provide order parameters for transformations that are difficult to see from local structure alone.
